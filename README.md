# おへやコンパス

**間取りと家具の悩みをなくす、お部屋づくりナビ**

> Move pixels before you move furniture.
>
> 家具を動かす前に、ピクセルを動かそう。

家具が入るか、椅子を引けるか、ドアを開けられるか。部屋と家具の寸法を入れて、ブラウザで気軽に試せる配置シミュレーターです。

## はじめ方

`index.html` をブラウザで開くだけ。インストール・ビルド・アカウント登録は不要です。

保存先を安定させる場合は、このフォルダで `python3 -m http.server 8000` を実行し、ブラウザで `http://localhost:8000` を開いてください。

## できること

- 部屋の追加・削除、寸法変更
- 家具・柱・部屋の欠けの追加、寸法変更、回転、複製
- L字などの直角の間取りを「欠け」で再現
- 家具をドラッグして配置・部屋間移動
- 1cm／0.1cmモード、矢印ボタンによる微調整
- 壁・家具の端への吸着（Shiftで一時解除）
- 重なる位置の赤枠・移動不可表示、はみ出し警告
- 壁・柱・欠けまでの距離表示
- 開き戸・引き戸用のスペースを枠外にも配置
- 椅子を引くための「椅子空間」の配置
- 部屋数に依存しない縮尺、拡大・縮小
- ブラウザ内への自動保存、JSONでの書き出し・読み込み

## 操作

1. 部屋名をクリックし、横幅・奥行きをcmで入力します。
2. 必要な家具やスペースを追加し、寸法を入力します。
3. ドラッグで配置します。カーソルが別の部屋に入ると移動先が切り替わります。
4. 重なったまま離すと元に戻ります。寸法入力による重なりは警告を表示するので、位置や寸法を調整してください。
5. 配置が決まった柱・欠けなどは「位置を固定」にチェックします。

横幅と奥行きはTab／Shift＋Tabで切り替えられます。移動単位はドラッグと矢印ボタンに適用されますが、吸着時は正確に接する位置を優先します。

## 保存について

データは同じブラウザ・同じサイトのlocalStorageに保存されます。端末間の同期はありません。ブラウザデータの削除・プライベートブラウズ・保存制限などで失われる場合があります。大切な配置は「書き出し」でJSONを保存してください。チャット内プレビューの保存内容は自動では引き継がれません。

## GitHub Pagesで公開

このフォルダの内容をGitHubリポジトリのルートに追加します。GitHub Pagesの公開元に、そのブランチのルートを指定してください。外部ライブラリやバックエンドは使用していません。

## 初期版の制限

- 直角の間取りのみ対応。斜めの壁・曲線は未対応です。
- 開き戸の円弧は目安です。衝突判定は点線の長方形全体を使います。
- 確保スペース同士も重なりとして判定します。
- 距離は各方向に面が重なる柱・欠けの手前までを測ります。通常の家具は距離から差し引きません。
- 巾木、家具の突起、ドアの厚み、搬入経路などは計算しません。最終判断には実測が必要です。

## 構成

- `index.html`：画面
- `style.css`：スタイル
- `app.js`：配置・保存処理
- `icon.svg`：アプリアイコン

HTML・CSS・JavaScriptだけで動く初期版です。
